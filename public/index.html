    How to read philosophy without getting lost.

      This atlas is a map, not the territory: a deliberately selective set of schools, thinkers and lines of influence. Every line is a simplification of conversations that ran for generations.

      About the dates

      Schools rarely begin or end in a single year, and many ancient dates, especially in India and early China, are traditional or disputed. The blocks show conventional spans; the panels say when a date is uncertain.

      About the images

      Portraits are the lead images of English Wikipedia articles, shown only when the file is on Wikimedia Commons. Every panel links to its source; check the file page before reusing an image.

      The project

      A static site with no build step: HTML, CSS and plain JavaScript, with all content in bilingual data files. A sibling of Art-isms and Worldlines. Corrections are welcome on GitHub.
